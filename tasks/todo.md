## Обзор результатов реализации

1. **Замечание 1 (Черный фон вокруг персонажа в Chrome DevTools при эмуляции iPhone 16):**
   - Выявлена первопричина: Chrome DevTools подменяет `navigator.userAgent` на iPhone, из-за чего функция `isApplePlatform()` возвращала `true`. В результате Chromium на Windows 11 получал Apple HEVC `.mov` контейнеры, в которых движок Blink на Windows не поддерживает альфа-канал прозрачности, рисуя сплошной черный прямоугольник.
   - В `frontend/src/shared/device.ts` внедрена проверка движка Chromium (`window.chrome`, `navigator.vendor === "Google Inc."`). Для Chromium (включая режим мобильной эмуляции в DevTools) гарантированно отдается WebM (VP9 с альфа-каналом), а Apple HEVC `.mov` отдается строго подлинному Apple WebKit. Черный квадрат полностью устранен.

2. **Замечание 2 (Обрезка логотипа игры справа и слева на стартовом экране):**
   - Выявлена первопричина: унифицированный расчет `coverScale = Math.max(w / origW, h / origH)` для экранов смартфонов с узким соотношением сторон (iPhone 16: 393x852, ~19.5:9) приводил к масштабированию по высоте, из-за чего ширина изображения вылезала за пределы экрана и обрезала буквы «У» и «И» логотипа «УЛИТКРОШИ».
   - В `frontend/src/Registration/BaseAuthScene.ts` логика разделена: на мобильных устройствах (`isVert`) применяется `setDisplaySize(w, h)`, гарантируя, что 1080px ширины картинки полностью умещаются в экран от края до края без обрезки букв логотипа. Для ПК (`!isVert`) сохранен `coverScale`, исключающий горизонтальное сжатие персонажей на широких мониторах.

3. **Верификация:**
   - `npm run build:front` завершился успешно (0 ошибок).

## Обзор результатов реализации
1. **Первопричина:** 
   - Контейнер хедера `.ui-header-target` не имел явного `z-index` (значение 0/auto), в то время как контейнер шкалы опыта `.ui-exp-target` имел `z-40` и `pointer-events-auto`.
   - На мобильных экранах значение `expTop` было занижено до 165px, из-за чего плашка опыта шириной 960px и высотой 145px физически накладывалась верхним краем (до y=92.5px) на нижнюю половину хедера (от y=90px до 122px). В результате клики по монетам и аватару полностью перехватывались слоем ExperienceBar.
   - На кнопке монет `HeaderCoins` кликабельным был только микро-плюсик 40x40px, а не вся плашка баланса.
2. **Решение:**
   - `.ui-header-target` получил наивысший приоритет `z-50 pointer-events-none` (с `pointer-events-auto` на кнопках).
   - `expTop` на мобильном скорректирован до 195-205px (с `indTop` до 305-315px), устранив наложение шкалы опыта на хедер.
   - Вся плашка монет `HeaderCoins` стала полноценной интерактивной кнопкой для открытия магазина, а аватарка вызывает `NiceModal.show(ProfileEdit)` напрямую.
3. **Верификация:** `npm run build:front` успешно завершен (0 ошибок).
