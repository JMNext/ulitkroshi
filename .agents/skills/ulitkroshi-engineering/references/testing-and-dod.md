# Регламент Тестирования и Definition of Done (DoD)

## 1. Пирамида Тестирования

1. **Static Analysis & Types:**
   - `npm run lint` — отсутствие ошибок линтера.
   - `npx tsc --noEmit` (фронтенд) и `npx tsc --project backend/tsconfig.json --noEmit` (бэкенд).
2. **Unit Tests:**
   - Математика восстановления параметров питомца (сытость, энергия, здоровье).
   - Валидаторы фруктового PIN и номеров телефонов.
   - Античит-калькуляторы допустимости игровых очков.
3. **Integration Tests:**
   - Эндпоинты `/auth/verify-otp`, `/auth/login-pin`, `/auth/refresh`, `/auth/logout`.
   - Сервис начисления наград `/game/reward` с проверкой транзакционности.
4. **E2E Smoke Tests:**
   - Загрузка PWA в браузере.
   - Прохождение онбординга / авторизации.
   - Главная сцена: реакция персонажа на кормление и мытье.
   - Запуск мини-игры и корректное начисление монет на баланс.

## 2. Чек-лист перед коммитом и деплоем (DoD)

| Этап | Команда / Действие | Критерий успеха |
| :--- | :--- | :--- |
| **Код** | `npm run lint` | 0 errors, 0 warnings. |
| **Типы** | `npm run build:front` | Успешная компиляция бандла в `dist/`. |
